# Как обновить сайт на GitHub Pages

## 🚀 Быстрая инструкция (3 шага)

Когда вы хотите изменить что-то на сайте:

### 1. Внесите изменения локально

Отредактируйте нужные файлы в вашем редакторе кода. Например:
- `App.tsx` — основная структура сайта
- `constants.ts` — данные (опыт работы, проекты, контакты)
- `components/` — отдельные компоненты
- `index.css` — стили

### 2. Проверьте изменения локально

Убедитесь, что dev-сервер запущен:
```bash
npm run dev
```

Откройте http://localhost:3000 и проверьте, что всё выглядит правильно.

### 3. Опубликуйте изменения

```bash
git add .
git commit -m "Описание изменений"
git push
```

**Готово!** Через 1-2 минуты изменения появятся на https://dun4ev.com/

## 📝 Подробная инструкция

### Что можно менять и где

#### 1. **Личная информация и контакты**
**Файл:** `constants.ts`

```typescript
export const SOCIAL_LINKS = {
  linkedin: 'https://linkedin.com/in/ваш-профиль',
  email: 'ваш@email.com',
  phone: '+381 XX XXX XXXX'
};
```

#### 2. **Опыт работы**
**Файл:** `constants.ts` → массив `JOBS`

```typescript
export const JOBS: Job[] = [
  {
    id: 1,
    company: 'Название компании',
    position: 'Должность',
    period: '2020 — Настоящее время',
    description: 'Описание работы...',
    technologies: ['Python', 'React', 'Docker'],
    link: 'https://company.com'
  },
  // ... добавьте больше записей
];
```

#### 3. **Проекты**
**Файл:** `constants.ts` → массив `PROJECTS`

```typescript
export const PROJECTS: Project[] = [
  {
    id: 1,
    title: 'Название проекта',
    description: 'Описание проекта...',
    technologies: ['Python', 'FastAPI'],
    link: 'https://github.com/username/repo',
    image: '/images/projects/project-name.png'
  },
  // ... добавьте больше проектов
];
```

#### 4. **Текст "О себе"**
**Файл:** `App.tsx` → секция `id="about"`

Найдите строки около 112-120 и отредактируйте текст в параграфах `<p>`.

#### 5. **Заголовок и подзаголовок**
**Файл:** `App.tsx`

```tsx
<h1>Ваше Имя</h1>
<TypingEffect text="Ваша должность" />
```

#### 6. **Изображения проектов**
Поместите изображения в папку `public/images/projects/` и укажите путь в `constants.ts`:
```typescript
image: '/images/projects/my-project.png'
```

#### 7. **Стили и цвета**
**Файл:** `index.css`

Можете изменить цветовую схему, шрифты и другие стили.

## 🔄 Полный рабочий процесс

### Пример: Изменение email

1. **Откройте файл** `constants.ts`

2. **Найдите и измените:**
   ```typescript
   export const SOCIAL_LINKS = {
     linkedin: 'https://linkedin.com/in/andrej-dunajev',
     email: 'новый@email.com',  // ← ИЗМЕНИЛИ ЭТО
     phone: '+381 XX XXX XXXX'
   };
   ```

3. **Сохраните файл** (Cmd+S / Ctrl+S)

4. **Проверьте локально:**
   - Откройте http://localhost:3000
   - Убедитесь, что новый email отображается

5. **Опубликуйте:**
   ```bash
   git add constants.ts
   git commit -m "Обновил email адрес"
   git push
   ```

6. **Дождитесь деплоя:**
   - Зайдите в https://github.com/Dun4ev/dun4ev.github.io/actions
   - Дождитесь зелёной галочки ✅ (1-2 минуты)
   - Обновите https://dun4ev.com/

## 🛠️ Устранение проблем

### Изменения не появляются на сайте?

1. **Проверьте статус деплоя:**
   - https://github.com/Dun4ev/dun4ev.github.io/actions
   - Должна быть зелёная галочка ✅

2. **Очистите кеш браузера:**
   - Cmd+Shift+R (Mac) или Ctrl+Shift+R (Windows)

3. **Подождите 2-3 минуты:**
   - GitHub Pages может кешировать контент

### Dev-сервер не запускается?

```bash
# Остановите текущий процесс (Ctrl+C)
# Переустановите зависимости
npm install
# Запустите снова
npm run dev
```

### Ошибка при git push?

```bash
# Проверьте статус
git status

# Если есть конфликты, посмотрите что изменилось
git diff

# Если нужно отменить изменения
git restore имя-файла
```
