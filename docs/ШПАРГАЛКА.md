# 🚀 Шпаргалка: Обновление сайта

## Три простых шага:

### 1️⃣ Измените файлы
Отредактируйте нужные файлы в редакторе

### 2️⃣ Проверьте локально
```bash
npm run dev
```
Откройте http://localhost:3000

### 3️⃣ Опубликуйте
```bash
git add .
git commit -m "Описание изменений"
git push
```

**Готово!** Через 1-2 минуты изменения будут на сайте.

---

## 📁 Основные файлы для редактирования

| Что менять | Файл |
|------------|------|
| Контакты, email, телефон | `constants.ts` → `SOCIAL_LINKS` |
| Опыт работы | `constants.ts` → `JOBS` |
| Проекты | `constants.ts` → `PROJECTS` |
| Текст "О себе" | `App.tsx` → секция `#about` |
| Имя и должность | `App.tsx` → `<h1>` и `<TypingEffect>` |
| Изображения проектов | `public/images/projects/` |
| Стили и цвета | `index.css` |

## ⚡ Полезные команды

```bash
# Запустить dev-сервер
npm run dev

# Проверить статус git
git status

# Посмотреть изменения
git diff

# Собрать production версию
npm run build

# Просмотреть production версию
npm run preview
```
